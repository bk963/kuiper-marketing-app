# Kuiper Marketing App

**Domain**: marketing.kuiper-safety.de
**Stack**: Next.js 15 App Router + Tailwind + PocketBase
**Auth**: JWT + Marketing-PB-Superuser
**Doku**: `docs/` (Phasen + Architektur)

## Sub-Apps

- 📊 Dashboards (Traffic, SEO, Ads, Conversions)
- 🎯 Landingpages (CMS + A/B-Tests)
- 📝 Content (Lead-Magnete, Email-Templates, Forms)
- 🤖 KI-Werkzeuge (Social-Gen, SEO-Recommend, LP-Gen)
- 📣 Kampagnen + Automationen
- 📍 Tracking-Center (UTM/Pixel/CAPI)
- ⚙️ Admin (Integrations, Alerts, Reports)
